# Calculator

Desktop-калькулятор на WPF (.NET Framework 4.7.2) с двумя режимами -
обычным (`MainWindow`) и инженерным (`Window1`, тригонометрия,
логарифмы, факториал и т.д.), переключаемыми цветовыми темами и
файловым логом истории вычислений (`history.log`).

## Структура проекта

```
Calculator/
├── App.xaml, App.xaml.cs        # точка входа, хранит только текущую тему
├── Views/                       # окна приложения (представление)
│   ├── MainWindow.xaml(.cs)     # обычный калькулятор
│   └── Window1.xaml(.cs)        # инженерный калькулятор
├── Services/                    # бизнес-логика
│   ├── CalculatorService.cs     # арифметика, разбор ввода, форматирование
│   ├── HistoryService.cs        # чтение/запись истории в history.log
│   └── Interfaces/
│       ├── ICalculatorService.cs
│       └── IHistoryService.cs
├── Infrastructure/
│   └── ThemeManager.cs          # переключение цветовых тем приложения
└── Properties/                  # стандартные файлы проекта .NET
```

## Модули и зоны ответственности

| Модуль | Пространство имён | Назначение |
| --- | --- | --- |
| Views | `Calculator.Views` | Окна приложения: разметка и обработчики событий элементов управления. Вызывают `Services` через интерфейсы. |
| Services | `Calculator.Services` | `CalculatorService` - арифметика и разбор ввода; `HistoryService` - чтение/запись истории в файл. Оба реализуют интерфейсы из `Services.Interfaces`, что позволяет заменить реализацию (например, хранить историю в БД) без изменения `Views`. |
| Infrastructure | `Calculator.Infrastructure` | Сквозная логика, не относящаяся к предметной области калькулятора - переключение цветовых тем (`ThemeManager`). |

## Сборка и запуск

Открыть `Calculator.sln` в Visual Studio 2019/2022, дождаться восстановления
зависимостей и нажать **Start** (F5). Целевая платформа - .NET Framework 4.7.2.
